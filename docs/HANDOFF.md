## 4. Deploy ฟรี — GitHub Pages (แนะนำ)

workflow เขียนรอไว้แล้วที่ `.github/workflows/deploy.yml` — push ขึ้น branch `main` แล้วมันจะ
publish ให้เอง ไม่ต้อง build อะไร

repo อยู่ที่ **https://github.com/Teerapab149/Teerapab149.github.io** และ
**Pages เปิดใช้งานแล้ว** — ตรวจสดเมื่อ 2026-07-30 ว่า https://teerapab149.github.io/
เสิร์ฟหน้าเวอร์ชันอังกฤษ + About me จริง (ทั้ง 4 หน้าตอบ 200) ดังนั้น
**push เข้า `main` = เผยแพร่ทันที** รอ 1-2 นาทีให้ workflow รันจบ

ถ้าวันหนึ่งเว็บไม่อัปเดตหลัง push ให้ดูแท็บ Actions ว่า job `deploy` เขียวไหม
· ถ้าไม่มี workflow รันเลย ให้เช็ค **Settings → Pages → Build and deployment → Source = GitHub Actions**

ถ้า push ใหม่แล้วเว็บไม่อัปเดต ให้ดูแท็บ Actions ว่า job `deploy` เขียวไหม
· ถ้าไม่มี workflow รันเลย แปลว่ายังไม่ได้ตั้ง Source เป็น GitHub Actions

**ทางเลือกฟรีอื่น ๆ** (ถ้าไม่อยากใช้ GitHub Pages)
- **Cloudflare Pages** — ต่อ repo แล้วตั้ง build command ว่าง, output directory = `/` · ฟรี ไม่จำกัด bandwidth
- **Netlify** — ลาก folder ทั้งอันไปวางบนหน้า drop ได้เลย ไม่ต้องมี git
- **Vercel** — import repo, framework preset = Other

ทุกเจ้าเสิร์ฟไฟล์ static ตรง ๆ ไม่ต้อง build ดังนั้นย้ายไปมาได้อิสระ

**ทุก path ในหน้าเว็บเป็น relative (`assets/...`) ทั้งหมด** — ย้ายไป subpath ไหนก็ไม่พัง
อย่าเปลี่ยนเป็น absolute path (`/assets/...`) เด็ดขาด ไม่งั้น GitHub Pages แบบ subpath จะรูปหายทั้งหน้า

## 8. กติกาของหน้านี้ (สืบทอดจากโปรเจกต์ต้นทาง)

1. **ห้ามซ่อนเนื้อหาไว้หลัง JS** — ห้ามใส่ `opacity: 0` แล้วรอ scroll reveal เด็ดขาด
   ถ้า JS ไม่ทำงาน เนื้อหาทั้งหมดต้องยังอ่านได้ (มีข้อยกเว้นเดียวคือ gallery สองอันที่ app.js สร้าง
   ซึ่งถ้าไม่มี JS ก็แค่หายไป ไม่ทำให้เนื้อหาหลักพัง)
2. **ห้ามให้ body scroll แนวนอน** — ทดสอบที่ 1440 / 1024 / 768 / 390 / 360 px ทุกครั้งที่แก้ layout
   ตารางกับ code block ต้อง scroll ในกล่องตัวเอง
3. **ประโยคภาษาไทยห้ามลงท้ายด้วยจุด** — ประโยคอังกฤษกับตัวย่อไทยยังใส่ได้
4. **ไม่เกิน 3 สีต่อวิว** — ม่วง brand + เทากลาง + accent (เขียวมิ้นต์) ใช้เฉพาะความหมาย "ผ่าน/ยืนยันแล้ว"

### กับดักที่เจอจริงตอนทำ (อย่าทำซ้ำ)

- **`.portrait` ต้องมี `width: 100%` คู่กับ `max-width` + `margin-inline: auto`** ที่ ≤900px
  ไม่งั้นรูปหดเหลือ 192px เพราะ **auto margin ปิด stretch ของ grid item** แล้วกล่องหดตาม fit-content
- **parallax ต้องใส่ที่ `.portrait__frame` ไม่ใช่ที่ `<figure>`** เพราะ figure เป็นเป้าของ `.up`
  และ `.js-anim .up.is-in { transform: none }` specificity สูงกว่า → transform ที่ตัว figure ถูกกินเงียบ ๆ
- **ตัวโครงร่างต้องอยู่ใน `@supports (-webkit-text-stroke: …)`** ไม่งั้นเบราว์เซอร์ที่ไม่รู้จัก
  จะเหลือแค่ `color: transparent` = นามสกุลหายไปทั้งคำ (ผิดกติกาข้อ 3 ของ `CLAUDE.md` เต็ม ๆ)
- **`--honey-ink` ใช้ได้แต่บนพื้นครีม** บนแผงมอสมันเหลือ 1.7:1 — บนมอสต้องใช้ `--honey` (4.7:1)
- **เส้น scrawl บนคำต้องย้ายลงมาเป็นเส้นใต้เมื่อคำเป็นตัวโครงร่าง** ค่า inset ปกติวาดพาดกลางคำ
  ซึ่งบนตัวโครงร่างขนาดใหญ่อ่านเป็น "ขีดฆ่าชื่อ" (ดู `.cover__name .mark-wrap > .scrawl`)
- **`.stage` ต้องมี `background` กับ `z-index: 1`** ไม่งั้น cover ที่ pin อยู่จะทะลุขึ้นมาให้เห็น
  แทนที่จะถูกทับ · และ **`.cover` ต้องประกาศ background ของตัวเองไว้หลัง `.stage`**
  เพราะ specificity เท่ากัน ใครอยู่ท้ายไฟล์ชนะ — ตอนแรกลืมข้อนี้แล้วแผงกลายเป็นครีม
  ตัวหนังสือครีมบนครีม = จอแรกว่างเปล่าทั้งจอ
- **การ pin ต้องวัดว่า cover สูงพอดีจอไหม ห้ามเดาด้วย media query** — panel ที่สูงเกินจอแล้ว pin
  จะซ่อนส่วนที่เกินไว้ตลอดกาล · โน้ตบุ๊ก 1366×768 กับ 1280×720 คือจุดที่เดาแล้วพลาด
  (แถวข้อมูลแถวสุดท้ายหายไปเลย) · ตอนนี้ `verdure.js` วัด `cover.scrollHeight <= innerHeight`
  แล้วค่อยใส่ `html.is-pinned` และวัดใหม่ทุกครั้งที่ resize
  · และมี `@media (max-height: 940px)` รีดอากาศของ cover ลง (padding, gap, ขนาดชื่อผูกกับ `svh`)
  เพื่อให้จอเตี้ยยัง**ผ่าน**เกณฑ์ ไม่ใช่ปล่อยให้ฟีเจอร์เงียบไป
- **`--cp` ต้องวัดจากขอบบนของ hero ไม่ใช่จาก cover** เพราะ cover เป็น sticky
  พอ pin แล้ว rect ของมันหยุดขยับ ค่าที่คำนวณจะค้างที่ 0 ตลอด
- **`html.is-ready` รอ `document.fonts.ready` (cap 700ms)** ถ้าเริ่ม wipe ตอน Kanit ยังสลับฟอนต์
  ตัวอักษรจะกระตุกกลางแอนิเมชัน · cap ไว้เพื่อไม่ให้ CDN ช้าทำให้ cover ค้างที่ start state
- **`clip-path` end state ต้องใช้ inset ค่าติดลบ** (`inset(-32% -7%)`) ถ้าใช้ `inset(0)`
  มันจะตัดพอดีขอบกล่อง = เส้น scrawl ที่ห้อยใต้นามสกุลหายไป
- **pill `00 — scroll` ทับแถวข้อมูลบนจอ 768px** เลยซ่อนตอนอยู่บน cover ด้วย `.bar--dark ~ .count`
  (ใช้ class ที่มีอยู่แล้ว ไม่ต้องเพิ่ม JS) · บน cover มี cue ของตัวเองอยู่แล้วจึงไม่เสียอะไร

**กรอบรูปเป็นทรง arch ไม่ใช่ทรงแคปซูล** — ตั้งใจให้ไม่เหมือน `.capsule` / `.grow__card`
เพราะสองอันนั้นต้องอ่านว่าเป็น "วัตถุเดียวกันที่กำลังเปิดออก" ตอน scroll
ถ้าเอารูปตัวเองไปใช้ทรงเดียวกัน คนจะอ่านเป็นวัตถุที่สามและ effect นั้นพัง

**ช่องว่างก่อนคำที่มีเส้นวงกลม (`.mark-wrap`) ต้องอยู่นอก `<span>`** — ตอนแปลเป็นอังกฤษเคยเขียน
`people<span class="mark-wrap"> actually use…` แล้วช่องว่างหน้าคำถูกกลืนหาย เพราะ leading space
ที่ต้นของ inline-block ถูก collapse → อ่านเป็น "peopleactually" · ภาษาไทยไม่เจอปัญหานี้เพราะไม่มีเว้นวรรค

**ตรวจ responsive ด้วย iframe ได้เร็วกว่า resize จริง** — สร้าง iframe กว้างตามที่ต้องการทดสอบ
โหลดหน้าเข้าไป แล้วไล่ `getBoundingClientRect()` ทุก element ข้ามตัวที่อยู่ใต้กล่อง `overflow-x`
(ดูเหตุผลที่ห้ามใช้ `scrollWidth` ใน §10) · 4 หน้า × 5 ความกว้าง จบใน JS call เดียว
· **ข้อควรระวัง: iframe ที่วางไว้ `left:-9999px` จะไม่โหลดรูป `loading="lazy"`** ถ้าจะวัดรูปต้องวัดในแท็บจริง

### `assets/reveal.js` — engine กลางของทั้ง 5 หน้า

โหลด**ก่อน** verdure.js / app.js / motion.js ทุกหน้า (i18n.js อ่าน `window.__lmRestore` ตอนโหลด)
ถือสองอย่าง: line-mask engine กับ IntersectionObserver ที่แจก `.is-in`
· **ห้ามสร้าง observer ตัวที่สองในไฟล์อื่น** element ที่ถูก observe สองที่จะแย่งคลาสกัน

ข้อควรระวังของ line-mask ที่แลกมาด้วยบั๊กจริง:
- อ่านทั้งหมดก่อนเขียนทีเดียว (Range ละคำ) → เสีย layout รอบเดียว **วัดได้ 0.15ms/element**
- re-split เฉพาะตอน**ความกว้าง**ของ element เปลี่ยน — ถ้าไปฟังความสูงจะ loop ไม่จบ
  เพราะการ split เปลี่ยนความสูงเอง · debounce 180ms · ทดสอบแล้ว resize รัว 6 ครั้ง = rebuild 2 ครั้ง
- ถ้า child element กินเกิน 1.65 เท่า line-height (คือมันตกบรรทัด) **จะไม่ split** เลย
  เพราะจะฉีก `<em>`/`<svg>` ออกจากกัน → ตกไปใช้ `.up` · เกิดจริงที่ h1 ของ credit-tracker
  ตอนจอ ≤1024 ซึ่งถูกต้องแล้ว ไม่ต้องแก้
- **ห้าม split ภาษาไทยต่ำกว่าระดับบรรทัด** สระ/วรรณยุกต์เป็น combining mark จะ render พัง
