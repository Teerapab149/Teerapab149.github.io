# Teerapab Boonsri

**I analyse the system, then I build it.** Business Information Systems at Prince of
Songkla University — I sit between the people who use a system and the system itself:
requirements, business rules, the ER diagram, and then the code and the deploy.

Writing code is what makes my system design sharper. It is not the destination I am
aiming for.

**Looking for a co-operative education internship, 16 Nov 2026 – 7 Mar 2027**, as a
System Analyst, Business Analyst or Management Trainee.

### How I work

**Listen** — sit with the people who will use it, before anything is drawn ·
**Draw** — use cases, business rules, the ER diagram ·
**Build** — the code and the interface, mobile-first ·
**Ship** — deployed, then used by real people

On three of the four projects above I did all four stages myself. On MeguBot I stopped
after the second and handed the drawing to a developer.

**Analysis** Requirements elicitation · Business process flow · Functional specification · ER diagram & data modelling
**Build** Next.js · React · TypeScript · Prisma · PostgreSQL · Tailwind
**Cloud** Microsoft Azure (Bot Service, Language Studio, VM) · Docker · Nginx · REST APIs
**Design** Figma · wireframing · mobile-first · accessibility

I use AI as a working tool on every project. The architecture, the security and the
data-model decisions are mine, and I keep a written decision log I can walk you through.
