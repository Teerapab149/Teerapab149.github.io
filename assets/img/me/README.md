## `<img>` จริงอยู่ตรงไหน

`index.html` บรรทัด 113–118 ในจอแรก

```html
<figure class="portrait cover__portrait" style="--d:560ms">
  <div class="portrait__frame">
    <img src="assets/img/me/portrait.webp" width="1200" height="1600"
         fetchpriority="high" alt="Teerapab Boonsri">
  </div>
</figure>
```

`.portrait__frame` ใน `assets/verdure.css` จัดการทรงกรอบ เงา และการ crop ให้เองแล้ว
· `--d:560ms` คือคิวใน title sequence ของจอแรก — ภาพจะถูกเปิดออกจากกรอบด้วย `clip-path`
ไม่ใช่แค่จางขึ้น

**ถ้าเปลี่ยนชื่อไฟล์ ต้องแก้สองที่เสมอ** — `index.html` กับ `assets/curtain.js`
· `curtain.js` โหลดรูปนี้ล่วงหน้าตั้งแต่ม่านยังไม่เปิด ถ้าลืมแก้ ม่านจะเปิดมาเจอกรอบว่าง
แล้วรูปค่อยโผล่ตามทีหลัง

## ข้อกำหนดถ้าจะเปลี่ยนรูปในอนาคต

รูปตอนนี้ใช้ได้แล้ว หัวข้อนี้ไม่ใช่ใบสั่งของ — มันคือเกณฑ์ที่รูปตัวใหม่ต้องผ่าน
ถ้าวันหนึ่งเจ้าของอยากเปลี่ยน

- **แนวตั้ง อ้างอิงกรอบ 4:5** — `.portrait__frame` ตั้ง `aspect-ratio: 4 / 5` ไว้ตายตัว
  (4:5 เต็ม ๆ คือ 1200 × 1500) · ไฟล์ที่ใช้อยู่จริงเป็น 1200 × 1600 ซึ่งสูงกว่ากรอบ
  ส่วนเกินด้านล่างจึงถูกครอปทิ้ง — **สูงกว่า 4:5 ได้ แต่เตี้ยกว่าไม่ได้** เพราะจะโดนครอปข้าง
- **crop เป็น `object-fit: cover` ยึดขอบบน** (`object-position: top center`)
  ดังนั้น **หัวต้องไม่ชิดขอบบน** ต้องเว้นที่เหนือหัวไว้หน่อย
  ไม่งั้นโค้งของกรอบ (`border-radius: 240px 240px …`) จะกินหัวหายไป
  · บนจอใหญ่ยังมี parallax ที่ยืดภาพเป็น `height: calc(100% + 40px)` อีก 40px
  ส่วนที่ถูกกินเพิ่มคือขอบล่าง ไม่ใช่ขอบบน
- **นามสกุล `.webp`** · ถ้ามีแต่ JPG จากมือถือ ส่งมาได้เลย แล้วค่อยแปลง
- **กว้างไม่เกิน 1600px** — ใหญ่กว่านี้แค่ทำให้โหลดช้า · สองไฟล์ที่ใช้อยู่กว้าง 1200px
- พื้นหลังเรียบ ๆ แสงธรรมชาติ อ่านหน้าชัด · ไม่ต้องเป็นชุดครุยหรือชุดทางการก็ได้
  แต่ควรเป็นรูปที่กล้าส่งให้ HR ดู
- **`width` / `height` ใน `<img>` ต้องตรงกับขนาดจริงของไฟล์ใหม่** ไม่งั้น layout กระตุกตอนโหลด
- เครื่องนี้ไม่มี ffmpeg / ImageMagick / Python — วิธีแปลงที่ใช้ได้จริงอยู่ใน `docs/HANDOFF.md` §14

ทุกอย่างใต้ `assets/img/` ถูก GitHub Pages เสิร์ฟหมด ใครเดา URL ก็โหลดได้
ต่อให้ไม่มีหน้าไหนลิงก์ไปหา — `portrait-alt.webp` ที่ยังไม่ถูกใช้ก็โหลดได้เหมือนกัน
