# รูปตัวเอง (หน้าแรก · section "About me")

วางไฟล์ชื่อ `portrait.webp` ในโฟลเดอร์นี้ แล้วบอก Claude ว่า "ใส่รูปตัวเองแล้ว"
เพื่อให้เปลี่ยนกล่องเส้นประเป็น `<img>` ให้

| ชื่อไฟล์ | ภาพอะไร | ใช้ที่ไหน |
|---|---|---|
| `portrait.webp` | รูปตัวเอง ครึ่งตัวหรือหน้าอก แนวตั้ง | `index-verdure.html` section แรก |

## ข้อกำหนดของไฟล์

- **แนวตั้ง อัตราส่วน 4:5** (เช่น 1200 × 1500 px) — กรอบเป็นทรงโค้งด้านบน
  รูปจะถูก crop แบบ `object-fit: cover` ยึดขอบบน ดังนั้น **หัวต้องไม่ชิดขอบบนเกินไป**
  เว้นที่เหนือหัวไว้หน่อย ไม่งั้นจะโดนโค้งของกรอบกินหัว
- **นามสกุล `.webp`** — ถ้ามีแต่ JPG จากมือถือ ส่งมาได้เลย แล้วค่อยแปลง
- **กว้างไม่เกิน 1600px** — ใหญ่กว่านี้แค่ทำให้โหลดช้า
- พื้นหลังเรียบ ๆ แสงธรรมชาติ อ่านหน้าชัด · ไม่ต้องเป็นชุดครุยหรือชุดทางการก็ได้
  แต่ควรเป็นรูปที่กล้าส่งให้ HR ดู

## วิธีเปลี่ยนกล่องเป็นภาพจริง

ใน `index-verdure.html` แทนที่ทั้งก้อน

```html
<div class="slot slot--fill">…</div>
```

ด้วย

```html
<img src="assets/img/me/portrait.webp" width="1200" height="1500"
     fetchpriority="high" alt="Teerapab Boonsri">
```

`<div class="portrait__frame">` ที่ครอบอยู่จัดการทรงกรอบ เงา และการ crop ให้เองแล้ว
