## ข้อกำหนดของไฟล์

- **นามสกุล `.webp`** — ถ้ามีแต่ PNG/JPG ให้ส่งมาได้เลย แล้วค่อยแปลง (PNG จากสไลด์มักหนักเกินไปสำหรับเว็บ)
- **กว้างไม่เกิน 1600px** — ใหญ่กว่านี้ไม่ได้ช่วยให้ชัดขึ้นบนจอทั่วไป แต่ทำให้หน้าโหลดช้า
- **ตรวจก่อนอัปโหลดทุกภาพ** — ต้องไม่มีชื่อจริง รหัสนักศึกษาจริง หรือเกรดจริงของใครติดมาในภาพ
  ถ้ามี ให้เบลอหรือครอปออกก่อน
