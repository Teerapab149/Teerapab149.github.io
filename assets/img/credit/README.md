## ข้อกำหนดถ้าจะเพิ่มภาพใหม่

- นามสกุล `.webp` · กว้างไม่เกิน 1600px
- ตั้งชื่อให้อยู่ในกลุ่มเลขเดิม (`0x` นักศึกษา · `1x` ไดอะแกรม · `2x` admin)
  แทนที่จะเรียงเลขใหม่ทั้งชุด — เรียงใหม่แปลว่าต้องไล่แก้ `src` ทุกอันใน `credit-tracker.html`
  กับ `index.html` ตามด้วย
- **เปิดดูภาพทุกใบก่อนวางลงโฟลเดอร์นี้** ว่าไม่มีชื่อ รหัสนักศึกษา หรือเกรดของ**คนอื่น**ติดมา
  ถ้ามีต้องเบลอหรือครอปออกก่อน
- เครื่องนี้ไม่มี ffmpeg / ImageMagick / Python — วิธีแปลงที่ใช้ได้จริงอยู่ใน `docs/HANDOFF.md` §14
