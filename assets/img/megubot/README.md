# ภาพของ MeguBot

วางไฟล์ตามชื่อด้านล่างในโฟลเดอร์นี้ แล้วบอก Claude ว่า "ใส่รูป megubot แล้ว"
ส่งเป็น PNG จากการแคปหน้าจอ Discord ได้เลย เดี๋ยว Claude แปลงเป็น webp ให้เอง

| ชื่อไฟล์ | ภาพอะไร | ใช้ที่ไหน |
|---|---|---|
| `01-hero.webp` | บอตกำลังถูกใช้จริงในห้องแชต — คำสั่งกับคำตอบ | `index.html` + หัวเรื่อง `megubot.html` |
| `02-commands.webp` | รายการคำสั่งทั้งหมดที่บอตโชว์ | §03 |
| `03-tts.webp` | ตอนใช้ text to speech ในห้อง voice | §03 + `index.html` |
| `04-game.webp` | เกมตกปลาหรือเกมปลูกผัก | §03 + `index.html` |

## ⚠️ ก่อนอัปโหลด ต้องเบลอสิ่งเหล่านี้ก่อน

Discord เต็มไปด้วยข้อมูลของคนอื่นที่ไม่ได้ยินยอมให้เอาขึ้นเว็บสาธารณะ

- **ชื่อและรูปโปรไฟล์ของเพื่อนทุกคน** ที่ไม่ใช่ตัวคุณเอง — เบลอหรือครอปออก
- **ชื่อเซิร์ฟเวอร์ · ชื่อห้อง** ถ้าเป็นชื่อส่วนตัว
- **ลิงก์เชิญ (invite link)** — ถ้าหลุดคือใครก็เข้าเซิร์ฟเวอร์ได้
- **token ของบอต** ถ้ามีหน้าไหนที่เผลอโชว์ (ห้ามเด็ดขาด และถ้าเคยหลุดต้อง regenerate ใหม่)
- ข้อความในแชตที่มีเรื่องส่วนตัวของเพื่อน

ถ้าเบลอเองไม่สะดวก ส่งมาแบบดิบได้ แล้วบอกว่าให้เบลอตรงไหน Claude ทำให้ได้ในขั้นตอนแปลงรูป
