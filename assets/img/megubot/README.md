## 🔒 สิ่งที่ต้องเบลอทุกครั้งที่เพิ่มภาพ Discord ใหม่

Discord เต็มไปด้วยข้อมูลของคนอื่นที่ไม่ได้ยินยอมให้เอาขึ้นเว็บสาธารณะ
และทุกอย่างใต้ `assets/img/` ถูก GitHub Pages เสิร์ฟหมด ใครเดา URL ก็โหลดได้

- **ชื่อและรูปโปรไฟล์ของเพื่อนทุกคน** ที่ไม่ใช่ตัวเจ้าของเอง — เบลอหรือครอปออก
- **ชื่อเซิร์ฟเวอร์ · ชื่อห้อง** ถ้าเป็นชื่อส่วนตัว
- **ลิงก์เชิญ (invite link)** — ถ้าหลุดคือใครก็เข้าเซิร์ฟเวอร์ได้
- **token ของบอต** ห้ามเด็ดขาด · ถ้าเคยหลุดต้อง regenerate ใหม่ทันที
- ข้อความในแชตที่มีเรื่องส่วนตัวของเพื่อน

## ข้อกำหนดถ้าจะเพิ่มภาพใหม่

- เครื่องนี้ไม่มี ffmpeg / ImageMagick / Python — วิธีแปลงที่ใช้ได้จริงอยู่ใน `docs/HANDOFF.md` §14
